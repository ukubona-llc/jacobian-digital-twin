## I. The Mathematics of the Graph Jacobian

To scale the sensitivity analysis across multiple stakeholders (e.g., CEO, Planners, Board Members, Auditors), we must define a networked dynamical system.

Let $N$ be the number of nodes in our network. Each node $i$ has its own state vector $x_i \in \mathbb{R}^d$ representing its local pentad (sensation through action).
The global state of the enterprise is the concatenated vector $X = [x_1^T, x_2^T, \dots, x_N^T]^T \in \mathbb{R}^{N \cdot d}$.

The relationships between nodes are defined by an adjacency matrix $A \in \mathbb{R}^{N \times N}$, where $A_{ij}$ represents the coupling strength (or leverage) from node $j$ to node $i$.

The **Graph Jacobian** $J_G$ combines the local pentad sensitivities ($J_{local}$) with the network topology:

$$J_G = (I_N \otimes J_{local}) + (A \otimes W_{edge})$$

Where:

* $I_N$ is the identity matrix.
* $\otimes$ is the Kronecker product (expanding local dynamics into the global block matrix).
* $W_{edge} \in \mathbb{R}^{d \times d}$ is the transformation matrix dictating how a perturbation at one node's output layer translates into the sensation layer of an adjacent node.

### The 403 Sovereignty Protocol (Non-linear Masking)

To prevent network-wide "pilau collapse" (blandness/pedigree loss), the 403 protocol acts as a strict threshold. If the pedigree dimension of node $i$ drops below a critical value $\lambda$, that node severs its outbound connections.

Mathematically, we apply a Heaviside step function $H$ to the adjacency matrix dynamically:

$$A_{ij}(t) = A_{ij}(0) \cdot H(\text{pedigree}_j(t) - \lambda)$$

import numpy as np
from typing import Dict, Any, List
from jacobian import SimpleJacobian

class GraphJacobian:
    """
    Scales the SimpleJacobian across a network of nodes (e.g., Individual, Planners, Regulators).
    Implements the 403 Sovereignty Protocol to prevent cascading pedigree collapse.
    """
    
    def __init__(self, num_nodes: int = 5, node_dim: int = 256, threshold_403: float = 0.5):
        self.num_nodes = num_nodes
        self.node_dim = node_dim
        self.threshold_403 = threshold_403
        
        # Initialize local dynamics (the pentad for each node)
        self.local_jacobian = SimpleJacobian(dim=node_dim)
        
        # Adjacency Matrix (A): Randomly connected network of stakeholders
        # Scale down by num_nodes to ensure initial stability
        self.adjacency = np.random.rand(num_nodes, num_nodes) * (1.0 / num_nodes)
        np.fill_diagonal(self.adjacency, 0) # No self-loops in A; local dynamics handle that
        
        # Edge Transformation (W_edge): How output of node j affects input of node i
        self.w_edge = np.random.randn(node_dim, node_dim) * 0.01

    def _apply_403_protocol(self, pedigree_scores: np.ndarray) -> np.ndarray:
        """
        Dynamically masks the adjacency matrix based on the 403 sovereignty threshold.
        If node j's pedigree < threshold, it cannot influence other nodes.
        """
        active_mask = (pedigree_scores >= self.threshold_403).astype(float)
        # active_mask affects outgoing edges (columns of A)
        dynamic_adjacency = self.adjacency * active_mask[np.newaxis, :]
        return dynamic_adjacency

    def compute_global_jacobian(self, layer: str, pedigree_scores: np.ndarray) -> np.ndarray:
        """
        Computes J_G = (I_N ⊗ J_local) + (A(t) ⊗ W_edge)
        """
        # 1. Local Block Diagonal
        j_local = self.local_jacobian.sensitivity_matrices.get(layer, self.local_jacobian.sensitivity_matrices['attention'])
        identity_n = np.eye(self.num_nodes)
        local_block = np.kron(identity_n, j_local)
        
        # 2. Network Coupling Block
        dynamic_adj = self._apply_403_protocol(pedigree_scores)
        network_block = np.kron(dynamic_adj, self.w_edge)
        
        # Global Jacobian
        return local_block + network_block

    def propagate_network_shock(self, global_state: np.ndarray, global_perturbation: np.ndarray, 
                                pedigree_scores: np.ndarray, layer: str = 'attention') -> Dict[str, Any]:
        """
        Propagates a shock through the entire network, returning the updated state and condition numbers.
        """
        j_global = self.compute_global_jacobian(layer, pedigree_scores)
        
        # Forward pass the perturbation through the global network
        global_response = j_global @ global_perturbation
        
        # Check global stability
        condition_number = np.linalg.cond(j_global + 1e-6 * np.eye(self.num_nodes * self.node_dim))
        
        # Identify the most heavily impacted node (chunk the response by node_dim)
        node_impacts = [np.linalg.norm(global_response[i*self.node_dim : (i+1)*self.node_dim]) 
                        for i in range(self.num_nodes)]
        max_impact_node = int(np.argmax(node_impacts))

        return {
            'global_response': global_response,
            'network_condition_number': condition_number,
            'node_impacts': node_impacts,
            'max_impact_node': max_impact_node,
            '403_triggered_nodes': np.where(pedigree_scores < self.threshold_403)[0].tolist()
        }
